# RGBW visual preview limits

The 2D and 3D views use the same display approximation: the white channel is blended equally into the visible RGB channels, and a monotonic display curve lifts dim nonzero setpoints so scene changes remain visible on screen. A zero setpoint remains dark. The master intensity scales the displayed 3D light level.

This is a visual simulation only. The blend and display curve are not calibrated to fixture spectra, correlated color temperature, measured photometry, cabin surface reflectance, or an installed aircraft lighting system. No hardware output or photometric prediction is implied. Replace these approximations only when fixture and cabin measurement data are available and traceable.
